# Sistema de Login

Projeto desenvolvido para implementar um sistema de login com cadastro de usuários e painel principal.

## Funcionalidades

- Login de usuário
- Validação dos campos de login
- Cadastro de novos usuários
- Dashboard após o login
- Menu de navegação
- Correção da estrutura HTML
